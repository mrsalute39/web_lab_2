## Описание задания
  1. Научиться конфигурировать веб-сервер Nginx для работы с PHP через PHP-FPM.
  2. Освоить базовые принципы PHP (на примере phpinfo()).
  3. Повторить основы HTML: работа с формами, различными типами полей ввода.
  4. Освоить базовую обработку форм с помощью JavaScript без перезагрузки страницы.

Результат доступен по адресу http://localhost:8080.

## ⚙️ Как запустить проект
Клонировать репозиторий:
```
git clone https://github.com/mrsalute39/web_lab_2
cd httml_php_fpm_lab
```
Запустить контейнеры:

```
docker-compose up -d --build
```
Открыть в браузере: ```http://localhost:8080```

Содержимое проекта:

```docker-compose.yml``` — файл для сборки контейнеров

```www/form.html``` — форма

```www/script.js``` — скрипт

```nginx/default.conf``` — файл конфигурации nginx

```screenshots/``` — скриншоты
